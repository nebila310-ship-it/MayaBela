## Quick start for staff

1. Open the web app or install the pilot APK we sent you.  
2. Enter your **School ID**, phone/username, and temporary password.  
3. On first login, **set a new password** (at least 10 characters). No SMS code is required for password change.  
4. Parents register / link a child with **Student ID + date of birth**, then wait for school approval.
