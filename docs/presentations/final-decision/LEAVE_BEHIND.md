## English — what each body should remember

| You are | You will use | The rule |
|---------|--------------|----------|
| Directors / Principal / VP | Dashboard, reports, grade approvals, quality, campuses | Leadership sees the school every morning in one place |
| Registrar / student affairs | Students, parent-link approvals, transfers, discipline | Parents link with Student ID + date of birth; school approves |
| Finance / store / HR | Fees, inventory, staff directory, buses | Money and stock leave a trail |
| Teachers | Classes, attendance, homework, submit grades | You enter; leadership publishes |
| Parents | Child attendance, approved grades, fees, bus, messages | You see your child only — never an unapproved mark |
| Drivers | Route, passengers, QR, live location | Parents see “live” only while you are sharing |

**The sentence:** Teacher enters → leadership approves → then the parent sees.

**Pilot:** 30–60 days, one campus or grade band, then expand.
