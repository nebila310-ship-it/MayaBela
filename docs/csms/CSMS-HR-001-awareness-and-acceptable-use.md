# CSMS-HR-001 — Awareness and acceptable use

## MaJo staff

- No production service-role key in chat, tickets, or screenshots.  
- No student row dumps. Counts and function names only.  
- Laptops: screen lock, unique passwords, no shared platform-owner PIN.  
- New engineers read CSMS-POL-001 before a production credential.

## School staff (give this to the school admin)

- Temporary passwords change on first login (10+ characters).  
- School Admin and Finance keep authenticator MFA on. Classroom teachers are not forced.  
- Do not photograph other people’s report cards into a public channel.  
- Drivers only need the passenger list for their bus — the system now enforces that.

Acknowledgement: school admin signs the support note / this page at go-live. MaJo keeps a copy.
