1. Security posture (two evaluations, two answers)

INSA reviewers must not mix the two documents. The product CSMS was scored under the Cyber Security Audit and Evaluation Guideline v1.0 (May 2015 E.C., 40 pages). The operator was then checked against CMCSRS version 2.0 (97 pages). Different pass rules; different result.

Product CSMS — Guideline v1.0

PASS · Mature 86/100 (Table 1: 76–90). Zero Major NCs on the submitted TOE. People / process / technology CSMS adopted. Remaining items (external pentest, CC laboratory certificate, live apply window) are Minor / observations.

Operator — CMCSRS v2.0

FAIL — NOT CONFORMANT. Must-clause gaps: locally licensed cloud (6.29.k), organisation-held cloud keys (6.29.f), foreign outsourcing (6.2.e / 6.38.i), INSA accreditation (6.22/6.23), annual compliance letter (6.24), DSAP national files (6.37). Finding IDs MNC-V2-01 to MNC-V2-06.

CIA objectives the product is built to meet: School A cannot read School B; a role sees only what that role needs; drivers see only their bus; privileged desks (Admin, Finance) use a second factor; classroom teachers are not locked out of lessons.

4.2 CMCSRS v2.0 (operator)

Must clauses are pass/fail. Exceptional skips need INSA approval. MaJo is treated as a key private organisation processing CONFIDENTIAL children’s data. IoT, blockchain, and ICS are N/A with justification (CSMS-CMCSRS-001). Remaining Must gaps cannot be closed in Flutter: they need a locally licensed CSP or INSA exception, customer-managed keys or on-prem, accreditation, an annual letter, and DSAP files. 86/100 is not reprinted as a CMCSRS score.

5. What this documentation does not claim

  • A gazetted INSA certificate, gateway certificate, or Common Criteria laboratory (CB) certificate.
  • An independent web/API pentest letter (scheduled after staging apply — R10 / TV-09).
  • That the live hosted database already contains every INSA migration in source (R9 / TV-07).
  • Organisation custody of hosted disk encryption keys (MNC-V2-02 / TV-06).
  • That classroom teachers are forced onto MFA (explicitly not done).
  • That login logos were hidden (public branding is required so the login page can show a stamp without a JWT).
