3. Context of the auditee

MayaBela is a Flutter web/mobile ERP. Persistence is a single Postgres database on a hosted Supabase project. School rows sit in public.app_documents keyed by (collection, school_id, doc_id). The client ships an anon key. Authorisation is JWT school/role claims plus RLS and a write-guard trigger. Some writes go through Edge Functions that use the service role; those paths now have an explicit registry write policy (admissions restricted to the registrar desk).

The system stores children’s identity, attendance, marks, and (by collection design) health, counselling and safeguarding notes. That remains sensitive personal data of minors. The CSMS now states: School A cannot read School B; a driver sees only students whose transportId matches that driver’s busId; public web holds logos only. Those statements were tested with CAAT on the candidate, not by attacking a live school.
