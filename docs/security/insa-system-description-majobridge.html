2. What the system is

MaJo e-School Bridge (MayaBela) is a multi-tenant school information system (web and mobile) for Ethiopian schools. Asset type: Web Application. Asset code: MB-ESB-001. Version: 1.0.6. Live URL: https://www.majobridge.com (same product as https://majobridge.com). One deployment serves many school tenants. Each school’s students, staff, marks, fees, and files must stay inside that school.

In scope: students, classes, attendance, homework, grades, admissions, parent links; fees and payments; inventory/procurement; HR/staff accounts; transport (buses, drivers, assigned passengers, GPS of that bus); restricted health, counselling, and safeguarding notes; school login with JWT school and role claims; platform-owner console to provision schools; hosted persistence and dedicated/on-prem instances for schools that cannot share the hosted tenancy.

Out of scope: a school’s own campus CCTV, IoT, or blockchain; forcing MFA on classroom teachers, parents, students, or drivers (would lock live lessons).

3. How it behaves

  1. Tenant isolation. Every persistent row carries school_id. A JWT from School A cannot read or write School B. Isolation is enforced in the database (row-level security), not only in the client.
  2. Need-to-know desks. Teachers work on assigned classes. Finance records that a fee is paid. Drivers see only passengers on their bus. Parents see linked children. Admissions on the privileged path is a registrar function. Denied writes return an error and must not dump the school. Login page has no JWT: only the school logo is public; student files stay under schools/<id>/.
  3. Identity. Login: School ID + username + password + role. School Admin and Finance enroll authenticator MFA. Teachers are not forced. Eight failed tries in 15 minutes lock that username+role+school only. Security changes that could stop a live school go to staging first, then a notified window.

Security: CSMS with named CSO (General Manager until a dedicated hire), adopted policy, JWT/RLS/Edge controls, and CAAT tests (permission hardening, driver need-to-know, two-school isolation).
